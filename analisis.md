# Diferencia entre objeto global window y objeto nativo global (Math o JSON).

El objeto window representa la ventana del navegador y actua como objeto global y los objetos nativos Math y JSON son objetos que pertenecen a Javascript sin depender del navegador.
No hace falta escribir window.Math porque Javascript permite acceder directamente a los objetos globales sin necesidad de poner window.

# Categoria BOM u objeto nativo de JS.

window.open(). Pertenece a BOM.
parseFloat(). Pertenece a objeto nativo de JS.
Math.floor(). Pertenece a objeto nativo de JS.
navigator.userAgent. Pertenece a BOM.
